# Axo-Team

Портфолио-сайт и ПК-приложение (Windows) с одним набором функций: каталог проектов, документация в Markdown, внешние ссылки, регистрация, комментарии, баг-репорты и админка владельца.

Правила работы с репозиторием — в [AGENTS.md](./AGENTS.md). Решения и состояние этапов — в [docs/](./docs/README.md).

## Что уже есть

| Часть | Путь | Состояние |
|---|---|---|
| Сайт (Astro + Svelte) | `apps/web` | каталог проектов и страницы с документацией |
| Общие компоненты и типы | `packages/ui` | карточка проекта, индикатор связи с Supabase |
| API (Rust + Axum) | `services/api` | ещё не начат |
| ПК-приложение (Tauri 2) | `apps/desktop` | ещё не начато |

## Запуск

Нужны Node.js 24 или новее (в `.nvmrc` указана версия 26) и pnpm 12.

```sh
pnpm install
pnpm --filter web dev      # сайт на http://localhost:4321
```

Проверки и сборка:

```sh
pnpm -r check              # astro check + svelte-check
pnpm --filter web build    # статический сайт в apps/web/dist
```

## Переменные окружения

Сайт работает и без них. Чтобы в подвале показывался индикатор связи с Supabase, скопируй `apps/web/.env.example` в `apps/web/.env` и подставь адрес проекта и publishable-ключ. Оба значения публичные; секретные ключи в переменные с префиксом `PUBLIC_` класть нельзя.

## Как добавить проект в каталог

Создай Markdown-файл в `apps/web/src/content/projects/`. Имя файла станет адресом страницы, поля в шапке описаны в `apps/web/src/content.config.ts`. Это временный источник данных: после появления API каталог будет приходить из базы.
