# Axo-Team

Портфолио-сайт и ПК-приложение для Windows с одним набором функций и одними аккаунтами: каталог проектов, документация в Markdown, внешние ссылки, регистрация, комментарии, баг-репорты и админка владельца.

Правила работы с репозиторием — в [AGENTS.md](./AGENTS.md). Решения и состояние этапов — в [docs/](./docs/README.md).

## Как это устроено

```
сайт (apps/web)  ─┐
                  ├─ общий интерфейс (packages/ui) ─── Supabase: аккаунты + база (db/)
приложение (app) ─┘
```

Сайт и приложение показывают одни и те же экраны из `packages/ui` и работают с одной базой в Supabase. Аккаунт, созданный на сайте, подходит для входа в приложение, и наоборот; комментарий из приложения сразу виден на сайте. Своего сервера нет: доступ к данным ограничивают правила в самой базе (RLS).

| Часть | Путь | Что это |
|---|---|---|
| Сайт | `apps/web` | Astro + Svelte, публикуется на Vercel: https://axo-team.vercel.app |
| ПК-приложение | `app` | Tauri 2 (Windows). Лежит только в репозитории, см. [app/README.md](./app/README.md) |
| Общий интерфейс | `packages/ui` | экраны, вход и регистрация, работа с данными, проверки форм |
| База | `db` | таблицы, права и тесты прав, см. [db/README.md](./db/README.md) |

## Запуск

Нужны Node.js 24 или новее (в `.nvmrc` указана версия 26) и pnpm 12.

```sh
pnpm install
cp apps/web/.env.example apps/web/.env   # и подставь два значения из Supabase
pnpm dev                                 # сайт на http://localhost:4321
```

Проверки и сборка:

```sh
pnpm check                 # типы во всех частях
pnpm build                 # статический сайт в apps/web/dist
pnpm build:app             # интерфейс приложения в app/dist
```

## Переменные окружения

| Переменная | Где | Зачем |
|---|---|---|
| `PUBLIC_SUPABASE_URL` | `apps/web/.env`, `app/.env`, Vercel | адрес проекта Supabase |
| `PUBLIC_SUPABASE_PUBLISHABLE_KEY` | там же | публичный ключ Supabase |

Оба значения публичные и одинаковые для сайта и приложения. Секретные ключи Supabase в проекте не используются. Без переменных всё собирается, но вместо данных показывается сообщение «Supabase не подключён».

## Как стать владельцем (админом)

1. Зарегистрируйся на сайте обычным способом.
2. Выполни в Supabase (SQL Editor) запрос из раздела «Как стать владельцем (admin)» в [db/README.md](./db/README.md).
3. Открой `/admin/`. Отдельного пароля у админки нет: права привязаны к аккаунту.

## Как добавить проект в каталог

Войди под аккаунтом владельца, открой «Админка» → «+ Новый проект». Проект создаётся скрытым; когда описание и документы готовы, включи «Показывать в каталоге всем».
