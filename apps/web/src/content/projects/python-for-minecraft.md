## О проекте

Python for Minecraft — аналог модов «Kotlin for Forge» и «Fabric Language Kotlin», только для модов, написанных на Python.

## Платформы

- Загрузчики: NeoForge и Fabric.
- Версии Minecraft: 1.21.1 и 26.3.
