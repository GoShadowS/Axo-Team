# База данных

База живёт в Supabase, проект `Axo-Team`. Таблицы созданы напрямую, без механизма миграций.
Файлы здесь — точная запись того, что выполнено в базе, чтобы её можно было поднять с нуля.

| Файл | Что это |
| --- | --- |
| `schema.sql` | Таблицы, RLS-политики, права, триггеры. Выполнен в базе. |
| `seed.sql` | Стартовый каталог: 4 проекта, по одному документу и ссылке. Выполнен в базе. |
| `tests/rls.sql` | 65 проверок прав доступа. Создаёт тестовые данные и откатывает их. |
| `tests/fingerprint.sql` | Хэши схемы и прав, чтобы сравнить две базы. |

## Как менять схему

1. Изменить `schema.sql` и выполнить в базе только новую часть (SQL Editor в Supabase).
2. Запустить `tests/rls.sql` целиком одним запросом. Ожидаемый результат: `failed = 0`.
3. Если добавилась таблица — включить RLS и написать политику в том же изменении.

## Как поднять копию

В пустом проекте Supabase выполнить `schema.sql`, затем `seed.sql`, затем `tests/rls.sql`.

## Как стать владельцем (admin)

Роль нельзя поменять через сайт или приложение — только в базе:

```sql
update public.users set role = 'admin'
where id = (select id from auth.users where email = 'ваша@почта');
```
