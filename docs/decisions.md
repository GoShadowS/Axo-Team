# Решения

Что решено владельцем и что ещё открыто. Действующие правила — в [AGENTS.md](../AGENTS.md).

## Принято

### Хостинг сайта — Vercel (2026-11-12)

Сайт остаётся на Vercel. Проект привязан к репозиторию: каждая ветка получает превью, `main` — продакшн на https://axo-team.vercel.app.

### Своего сервера нет, миграций нет (2026-11-12)

Сайт и приложение обращаются к Supabase напрямую с публичным ключом. Rust-API, Render, Redis и `moka` из исходного плана не нужны.

Следствия:

- Вся защита данных — в базе: RLS-политики, права на столбцы, ограничения CHECK, триггер с лимитом частоты. Проверки в формах нужны для понятных сообщений, а не для защиты.
- Схема хранится одним файлом `db/schema.sql`. Изменения применяются в Supabase SQL-запросом и сверяются с файлом (`db/tests/fingerprint.sql`), права проверяются тестом `db/tests/rls.sql`.
- Админка — это обычные экраны; владельца отличает поле `role = 'admin'` в таблице `users`, которое нельзя изменить из клиента.

### Приложение живёт только в репозитории, в папке `/app` (2026-11-12)

Установщик нигде не публикуется. Его собирает GitHub Actions и кладёт в артефакты запуска.

### Одна экосистема (2026-11-12)

Сайт и приложение используют одни экраны (`packages/ui`), одну базу и одни аккаунты. Новая функция делается один раз в `packages/ui` и появляется в обоих местах.

## Открыто

### Видимость репозитория и лицензия

Исходный план рассчитывал на публичный репозиторий с лицензией MIT. Сейчас репозиторий приватный и без лицензии. В приватном репозитории сборка под Windows тратит минуты GitHub Actions вдвойне.

### Домен

В Vercel есть домен `axo-team.com`, он не подключён к проекту. Если его подключать, нужно обновить `site` в `apps/web/astro.config.mjs`, адрес сайта в настройках Supabase Auth и ссылку в `app/src/App.svelte`.

### Почта для писем подтверждения

Встроенная почта Supabase на бесплатном тарифе отправляет всего несколько писем в час. Для открытой регистрации понадобится свой SMTP (бесплатные тарифы есть, но нужна регистрация владельцем) либо отключение подтверждения почты.

### Подпись установщика

Без сертификата Windows SmartScreen предупреждает при запуске. Сертификат платный, бесплатного решения нет.
